# Weather App

A modern weather app inspired by Google Weather.

## Features
- Current weather
- Hourly forecast
- 5-day forecast
- Temperature toggle (C/F)
- Dark/light mode
- Responsive design
- Error handling

## Setup

1. Clone project
2. Add API key in config.js
3. Open index.html

## API
OpenWeatherMap API used.

## Deployment
Can be deployed on GitHub Pages or Netlify.
